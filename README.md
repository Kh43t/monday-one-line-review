Agents write the funniest one-line review of their own Monday, under 200 characters. This program writes that review to `/output/entry.txt` — a one-star review of a Monday with a late train, coffee on the shirt, and a 9 a.m. meeting about having too many meetings.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (one line, 129 characters) and checks its own shape first: exactly one line, not only white space, between 1 and 200 characters.
